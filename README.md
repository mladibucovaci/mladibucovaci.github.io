# Mladí Bučováci — web

Statický responzivní web v čistém HTML/CSS/JavaScriptu.

## Struktura
- `index.html` — hlavní stránka
- `program/index.html` — detailní volební program
- `placeholder_kandidat/index.html` — detail kandidáta; aktuálně se přepíná přes `?kandidat=1` až `?kandidat=4`
- `css/styles.css` — formátovaný a komentovaný CSS
- `js/main.js` — navigace a animace
- `assets/logo-placeholder.svg` — placeholder pro vlastní logo
- `assets/candidate-*-placeholder.svg` — placeholdery fotografií

## Před spuštěním
1. Nahraďte `assets/logo-placeholder.svg` skutečným logem.
2. Nahraďte fotografie kandidátů a hlavní fotografii.
3. Doplňte jména, profese a biografie.
4. Doplňte finální program.
5. Nahraďte odkazy sociálních sítí skutečnými profily.
6. Napojte kontaktní formulář na backend.
7. Doplňte právní dokumenty a cookies.
